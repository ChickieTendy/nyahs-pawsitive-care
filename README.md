# Nyah's Pawsitive Care - Version 1

This is a static website made with HTML, CSS, and JavaScript. No paid website builder is required.

## Files
- `index.html`: website content
- `styles.css`: design and mobile layout
- `script.js`: menu and care-request email form
- `assets/nyahs-pawsitive-care-flyer.jpg`: uploaded brand flyer

## Before publishing
1. Open `script.js` in a text editor.
2. Replace `REPLACE-WITH-YOUR-BUSINESS-EMAIL@example.com` with the business email address.
3. Open `index.html` in a browser and test the form.
4. Replace gallery placeholders with real photos you have permission to use.
5. Review all service wording, policies, pricing, and requirements before making the site public.

## Preview locally
Double-click `index.html`. No server is required for the basic preview.

## Free publishing option: GitHub Pages
Create a public GitHub repository, upload these files, and enable Pages from the repository settings. The site can use the free GitHub Pages address until you choose to buy a custom domain.

## Important privacy note
The request form does not store information on the website. It creates an email draft on the visitor's device. Do not add a database or collect sensitive pet/client information without appropriate privacy and security planning.
